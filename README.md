💻 Portfólio — Lucas Rocha

Bem-vindo ao meu portfólio pessoal! 🚀

Este projeto foi desenvolvido para apresentar minha trajetória profissional, experiências, projetos e informações de contato, reunindo em um único lugar um pouco sobre meu trabalho e minhas habilidades na área de tecnologia.

🌐 Sobre o projeto

O portfólio possui uma interface simples e objetiva, organizada em diferentes páginas para facilitar a navegação e apresentar minhas principais informações.

📌 Páginas

- 🏠 Início — Apresentação do portfólio.
- 👨‍💻 Experiência — Informações sobre minha trajetória e experiências profissionais.
- 🚀 Projetos — Projetos desenvolvidos e trabalhos realizados.
- 📬 Contatos — Formas de entrar em contato comigo.
- 📄 Currículo — Currículo profissional disponível em PDF.

🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript

📁 Estrutura do projeto

Portfolio_Lucas/

├── Curriculo_Lucas_Rocha.pdf

🚀 Como executar

1. Clone o repositório

git clone https://github.com/Luc4sR0cha/Portfolio_Lucas.git

2. Acesse a pasta

cd Portfolio_Lucas

3. Execute o projeto

Por ser um projeto desenvolvido com HTML, CSS e JavaScript, basta abrir o arquivo:

index.html

Também é possível utilizar uma extensão como Live Server no VS Code para executar o projeto em um servidor local.
